## Низкоуровневое программирование

Представлены следующие задания:
1) Дано три числа a,b,c. Найти максимальное из них, и вычтем его из двух других. (0 labs)
2) С начала суток прошло N секунд(N - целое). Найти количество секунд, прошедших с начала последней минуты. (1 labs)
3) Верно ли высказывание, что среди цифр заданного 3-хзначного числа есть одинаковые. (2 labs)
4) Даны натуральные числа m,n. Получить все их натуральные общие кратные, меньшие mn. (3 labs)
