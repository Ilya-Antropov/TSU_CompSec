## Низкоуровневое программирование

Представлены следующие задания:
1) Дано три числа a,b,c. Найти максимальное из них, и вычтем его из двух других. (0 labs)
2) С начала суток прошло N секунд(N - целое). Найти количество секунд, прошедших с начала последней минуты. (1 labs)
3) Верно ли высказывание, что среди цифр заданного 3-хзначного числа есть одинаковые. (2 labs)
4) Даны натуральные числа m,n. Получить все их натуральные общие кратные, меньшие mn. (3 labs)
5) Дано целое n > 2. Напечатать все простые числа из диапазона [2,n]. (4 labs)
6) Дан массив A, в котором нет повторяющихся элементов. Найти сумму его элементов, расположенных между максимальным и минимальным элементом. (5 labs)
7) Дана целочисленная квадратная матрица порядка n. Найти s - суммы элементов из 
заштрихованной области. (6 labs)
8) Интервал в булевом пространстве размерности n задан троичным вектором. Принадлежит ли булев вектор x этому интервалу? (7 labs)
9) 1. Построить таблицу значений функции y=(1+2x^2)e^(x^2), при заданных значениях аргумента x ∈ [0,1;1], h = 0,05.
   2. Вычислить значение функции In(1+x) = x - x2 / 2 + x3 / 3 - x4 / 4 + ... в точке x = x0. Сравнить полученное значение со значением соответствующей стандартной функции. (8 labs)
10) Реализовать программу на языке C, имеющую следующую структуру:
    k. Вводим количество элементов массива. Выделяется память под массив и заполняется случайными числами.
    i. Запускаем сортировку на C, подсчитываем время выполнения.
    m. Запускаем ту же сортировку на том же массиве, но написанную на Ассемблере, подсчитываем время.
    n. Проверить массив на упорядоченность, вывести результат.
    о. Сравнить время выполнения сортировки на разных языках.
    Сортировка: прямая вставка (9 labs)
