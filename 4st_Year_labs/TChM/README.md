Представлены следующие алгоритмы:
1) Метод пробных делений (Trial_division)
2) Метод Олвея (Alway)
3) Метод Ферма (Ferma)
4) Метод Полларда (Pollard)
5) Метод Гельфонда (Gelfond)
6) p-метод Полларда дискретного логарифмирования (pollard_dis_log)
7) Тесты на неприводимость полиномов (polinomial)
8) Тест на примитивность полиномов (polinomial)
